# Cours particuliers – Maths, Physique, Mécanique, Informatique (Tunisie)

Page promotionnelle statique (HTML / CSS / JS) en 3 langues : عربي, Français, English.

- **Numéros WhatsApp** : modifier `CONFIG` au début de `script.js`.
- **Google Classroom** : coller les liens par matière dans `CLASSROOM` au début de `script.js` (un bouton vide s'affiche « Bientôt disponible »).
- **Quiz de la semaine** : liste `QUIZZES` dans `script.js` (1 quiz par semaine, rotation automatique chaque lundi). La bonne réponse n'est pas dans le code : le professeur la vérifie dans le message WhatsApp reçu.
- **Photos** : dossier `photos/`.
- **Textes / langues** : objet `I18N` dans `script.js`.

Déploiement : automatique via GitHub Actions à chaque push sur `main`
(Settings → Pages → Source : **GitHub Actions**).
